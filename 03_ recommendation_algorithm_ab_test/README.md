# A/B-тест нового алгоритма рекомендаций в приложении с «бесконечной» лентой

**Цель:** рассчитать параметры A/B-теста и оценить, повышает ли новый алгоритм рекомендаций
ключевые метрики вовлечённости и монетизации в приложении с «бесконечной» лентой.

**Контекст:** у приложения две модели монетизации — платная подписка (просмотр без рекламы)
и показ рекламы для пользователей без подписки. Команда рекомендательных систем предложила
новый алгоритм, который должен показывать более релевантный контент.

**Задачи:**
1. Рассчитать параметры A/B-теста (размер выборки, длительность, MDE, уровень значимости и мощность).
2. Проверить корректность проведения теста (распределение по группам, отсутствие пересечений, соответствие ТЗ).
3. Проанализировать результаты: сравнить ключевые метрики между контрольной и тестовой группами.
4. Сформулировать вывод и рекомендации по внедрению нового алгоритма.

**Метрики:** вовлечённость (время в ленте, число просмотров, удержание) и монетизация
(конверсия в подписку, показы и клики по рекламе).

**Стек:** Python, pandas, numpy, matplotlib/seaborn, scipy, statsmodels.
